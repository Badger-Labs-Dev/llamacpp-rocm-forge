# r9700-llm-bench viewer

Static React + TypeScript + Vite app that reads `public/results.json` (generated by `../benchmark/generate_viewer_data.py` from the `results/` directory) and renders four views per model:

1. **Performance across versions** - depth-0 throughput for every ROCm/llama.cpp version (`run_id`) the model has been benchmarked against.
2. **Parameter sensitivity** - a tornado chart of the throughput swing between each swept parameter's best and worst tested candidate (from `--full-sweep`'s `tuning_log`), for a selected run.
3. **Recommended settings** - the winning config, each field annotated with how much it actually mattered per the sensitivity data above.
4. **MoE expert offload** - conditional on a `moe_offload_curve`; shows the smallest `--n-cpu-moe` that fits at each depth and the corresponding throughput curves.

## Regenerating the data

From the repo root, after benchmark runs exist under `results/`:

```bash
uv run benchmark/generate_viewer_data.py
```

Writes `viewer/public/results.json`, which Vite copies into `dist/` on build (and serves directly in dev mode via `public/`). Not committed - regenerate it, don't check it in (see `.gitignore`).

## Local development

```bash
npm install
npm run dev
```

## Building for GitHub Pages

```bash
npm run build
```

`vite.config.ts` sets `base: '/r9700-llm-bench/'` for GitHub Pages project-site hosting (`https://<user>.github.io/r9700-llm-bench/`). Override for a different hosting path with `vite build --base=/some/other/path/`.
