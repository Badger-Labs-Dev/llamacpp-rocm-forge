# llamacpp-rocm-forge viewer

Static React + TypeScript + Vite app that reads `public/results.json` (generated by `../benchmark/generate_viewer_data.py` from the `results/` directory) and renders up to six views per model:

1. **Performance across versions** - depth-0 throughput for every ROCm/llama.cpp version (`run_id`) the model has been benchmarked against.
2. **Selected-run depth curve** - separate prefill and generation charts across context depths, with missing and failed probes shown as gaps rather than interpolated values.
3. **Parameter sensitivity** - the throughput swing between each swept parameter's best and worst valid candidate (from the default auto-tune mode's `tuning_log`), for a selected run.
4. **Recommended settings** - the winning performance-tuned config plus capacity-selected offload settings. Partial runs are marked provisional; failed runs do not receive a recommendation.
5. **MoE expert offload** - conditional on a `moe_offload_curve`; shows the smallest `--n-cpu-moe` that fits at each depth and distinguishes measured, failed, and untested candidates.
6. **Dense layer offload** - conditional on a `dense_offload_curve`; shows maximum fitting `--ngl` per depth and distinguishes measured, failed, and untested candidates.

Every chart has a data table alternative. Prefill and generation use separate scales because their magnitudes differ substantially.

## Regenerating the data

From the repo root, after benchmark runs exist under `results/`:

```bash
uv run benchmark/generate_viewer_data.py
```

Writes `viewer/public/results.json`, which Vite copies into `dist/` on build (and serves directly in dev mode via `public/`). Not committed - regenerate it, don't check it in (see `.gitignore`).

## Local development

```bash
npm install
npm run dev
npm test
```

## Building for GitHub Pages

```bash
npm run build
```

`vite.config.ts` sets `base: '/llamacpp-rocm-forge/'` for GitHub Pages project-site hosting (`https://<user>.github.io/llamacpp-rocm-forge/`). Override for a different hosting path with `vite build --base=/some/other/path/`.
